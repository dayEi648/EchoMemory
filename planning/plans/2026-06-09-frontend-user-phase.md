# 2026-06-09 前端用户功能首期开发计划

## 范围

- 创建 `apps/frontend`，作为 Tauri 2.x + React 19 + TypeScript + Vite + Tailwind CSS 前端工程。
- 只真实实现用户相关功能：登录、注册、当前用户资料、资料编辑、用户搜索、公开资料、关注关系、用户标签、管理员用户管理。
- 首页、个人中心、管理后台、登录注册页面需要可用；音乐、专辑、播放、评论、空间动态等模块只做占位组件。
- 只开发亮色主题。

## 成功标准

1. 前端骨架
   - [ ] `apps/frontend` 包含可构建的 Vite/React/Tauri 工程结构。
   - [ ] 全局样式落地亮色主题设计 token。
   - [ ] 非用户模块不触发真实 API 请求。

2. 用户认证
   - [ ] 登录成功后保存 access token 与 refresh token。
   - [ ] 注册接口使用 multipart form，支持 `city` 字符串与头像字段。
   - [ ] 401 时尝试 refresh，refresh 失败后清理会话。

3. 用户页面
   - [ ] 首页展示当前用户概览、等级、标签与用户搜索入口。
   - [ ] 个人中心可编辑昵称、邮箱、手机号、性别、生日、简介、城市和头像。
   - [ ] 公开用户资料不展示邮箱、手机号、状态、安全分等敏感字段。

4. 管理后台
   - [ ] 仅管理员角色可进入用户管理。
   - [ ] 支持用户列表筛选、搜索、编辑、封禁、解封。
   - [ ] 其它后台模块只展示占位状态。

5. 验证
   - [ ] 先写前端测试，覆盖 API client、认证、城市字段、权限守卫和关键页面。
   - [ ] `npm run test` 通过。
   - [ ] `npm run lint` 通过。
   - [ ] `npm run build` 通过。
   - [ ] 使用浏览器检查桌面和窄屏视图，无文字溢出或重叠。

## 风险与约束

- 当前工作区原本不存在 `apps/frontend`，需要新建工程。
- `planning/api-documentations/openapi.json` 曾残留 `city_id`，前端以源码和已确认决策中的 `city` 字段为准。
- 本阶段不实现暗色主题和任何非用户业务功能。
- 首期前端只在进程内保存 access token 与 refresh token，不做本地持久化登录。
